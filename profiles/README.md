# Sample profiles

The public dashboard scores every posting against these profiles rather than
against a real candidate. They are ordinary CV files, loaded through the same
code path as a real CV and scored by the same scorer, so the public scores are
produced by the real system rather than an imitation of it.

None of them carry a salary floor. A real floor is private, and leaving it out
means the salary component rewards advertised pay without penalising any role
against a threshold nobody set.
